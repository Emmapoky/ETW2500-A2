## To read the report

Open `document/ErwynaSooW.html` in any web browser. This is the main document. `document/ErwynaSooW.pdf` is the same report as an attachment.

## To run the code and rebuild the report

1. Unzip this folder and keep its layout (`ErwynaSooW.Rproj`, `dataset/`, `document/`).
2. Double click `ErwynaSooW.Rproj`. RStudio opens with the project folder as the working directory.
3. In the RStudio console, run once: `install.packages("pacman")`
4. Open `document/ErwynaSooW.qmd` and click **Render**. The first render installs any missing packages, so it needs internet.
5. `document/ErwynaSooW.html` and `document/ErwynaSooW.pdf` are rebuilt. Every result comes from the code in the `.qmd` file and the two files in `dataset/`.

Full instructions, software versions and troubleshooting are in Section 2 of the report.
